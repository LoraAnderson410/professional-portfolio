Practical Tools & Guides

Practical references for tools, analysis, data quality, and problem solving.

I have always believed that part of being a good leader is helping people understand the work, not just telling them what to do. Over the years, I have created guides, training resources, checklists, and reference tools to make information easier to use and help people work with more confidence and independence.

I still build them when I am learning something new too. If I figure out something useful, my instinct is usually to document it so the next person does not have to start from scratch.

Why Guides?

Documentation is part of how I learn.

I rarely want to solve the same problem from scratch twice. If I learn a useful process, formula, query pattern, or decision framework, I usually capture it somewhere so I can reuse it.

That habit has followed me throughout my career. Good documentation makes work easier to repeat, easier to teach, easier to improve, and less dependent on one person's memory.

These guides are examples of that approach. Some are technical. Others help organize judgment and decision-making.

Decision Support

Choosing the right tool for the problem.

Technical skill is useful, but using the most complicated tool available is not the goal. Good problem solving includes knowing when a spreadsheet is enough, when a database makes sense, when visualization helps, and when a process problem is not really a technology problem at all.
